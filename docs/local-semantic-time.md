# 本地语义补充与交流间隔

本轮仅在本地验证，不代表已更新公开源码包或 GitHub。

## 检索

原有关键词、干员外号、史事卡检索保留。对未充分命中的知识问句，按需通过独立 CPU Worker 查询固定原作资料的语义索引；问候、其他干员的技能等精确问题、最新活动问题、已选定的史事进度不会因此额外走向量检索。

当前模型为 BAAI/bge-small-zh-v1.5，独立 `.semantic-venv` 安装 `requirements-semantic.txt`，主环境不导入嵌入依赖。索引仅包含固定知识 SQLite 中的正文、手写转录及原作台词/剧情资料，不向嵌入服务提交群友记忆，也不建立正面聊天示例库。

保留来源、说话人、阶段、页码和核验状态。低分、近似候选难以区分、Worker 忙或等待超过 200 毫秒时，回退原检索。最多取同一资料域的两段接近最高分的结果。已有资料时复用原摘录字数预算；原来未命中时，补足必要资料可能增加输入 Token，但不会增加 Luna 调用轮数。

首次离线建索引：`.semantic-venv/Scripts/python.exe scripts/build_semantic_index.py --allow-download`。模型已下载后省略该开关。固定资料发生变更后后台增量更新，聊天过程暂时使用原检索，不等待重建；未变化的文本块复用旧向量。服务启动预热，不在每条消息中加载模型。运行目录是 `runtime/semantic`，不要发布 Worker 认证文件、环境、模型缓存或私有运行状态。

临时禁用语义补充可为服务设置 `KALTSIT_SEMANTIC_DISABLED=1` 后重启；原检索继续工作。

## 时间间隔

只记录向当前对象实际成功发送的交流时间；测试窗口在正文显示并确认后记录。按群/私聊及对象隔离，不以其他群友发言替代当前对象的时间。短间隔同日交流不添加时间提示；跨天或较长间隔仅提供实际间隔，不推测离线、作息、思念或现实经历，不改变主动发言概率。

数据独立存放于会话目录的 `exchange-time.private.json`。初次没有记录就不猜，不回填未经核实的旧时间。不额外调用总结、情绪判断或润色模型。当前凯尔希角色卡、GPT-6 Luna high、Fast 关闭及同轮表达重组/气泡检查保留。

## 本地验证

179 项离线回归、3 项最终回复交付测试、合成 QQ 群聊/私聊全链路与确认回执测试通过。隔离索引测试验证只重算被修改的文本块。实际固定知识索引 2521 块，角色及原始知识资料 40 项 SHA-256 未变。

两次实际 Luna 测试仅作为样本：检查权限约 7.3 秒，模拟三天后继续交流约 11.7 秒。没有额外网络搜索。30 次热缓存检索抽样 P95 约 27 毫秒；冷启动、模型网络及复杂问题耗时不能由这些样本保证。
