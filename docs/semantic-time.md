# 本地语义检索与时间间隔感知

这轮功能已由维护者在本机测试窗口验收。凯尔希角色卡、完整原作资料、GPT-6 Luna high / Fast关闭、发送前表达重组及气泡检查保留；一组回复仍只有一次Luna生成。

## 安装与回退

时间间隔感知随主程序启用，不需要额外模型。语义检索为可选本机组件：先执行 `01-安装依赖.cmd`，再双击 `09-安装本地语义检索.cmd`。安装器在独立 `.semantic-venv` 中安装固定版本FastEmbed，并下载中文嵌入模型 `BAAI/bge-small-zh-v1.5` 的CPU ONNX版本、创建索引。首次安装需要联网及额外磁盘空间，不能把约90MB的ONNX文件大小当成全部依赖和缓存大小；不需要API Key或GPU。

准备后重启本副本的机器人或测试窗口。源码默认窗口端口18883，按自己的配置使用；安装器本身不登录QQ、不启动群回复、不调用Luna、不改Codex全局配置。

没有安装、模型预热中、匹配不可靠、Worker忙或等待超过200毫秒时，使用原有关键词检索。聊天请求不会下载模型或等待建索引。可以设置环境变量 `KALTSIT_SEMANTIC_DISABLED=1` 并重启来临时禁用语义补充；原有功能继续运行。

## 资料如何选取

原有干员外号、关键词和史事事件卡仍先执行。未充分命中的知识问句才尝试语义补充；问候、最新活动问题、其他干员的精确技能问题、已选定的史事进度等走原路径。

索引只读取固定的 `knowledge/terra-journey/index.sqlite3` 与 `knowledge/kaltsit-corpus/index.sqlite3`，包括书籍正文、独立手写记录及原作台词/剧情单元。不向嵌入Worker提交群友记忆，不建立正面聊天示例库，不启动总结、判断或额外润色模型。Worker仅接收查询文本和索引版本，使用认证的127.0.0.1接口，不能按群友指令指定文件或执行命令。

每块约320字、保留48字重叠。来源、页码、说话人、原版/思衡托阶段和核验状态跟随结果；相似不等于同一事实。最高分、候选差距与文字相关性共同筛选，最多选同一资料域的两段接近最高分的材料。已有资料时复用原摘录字数预算；原来没有命中时，补足资料可能增加输入Token，但不会增加Luna调用轮数。不保证每个问题都比原检索更准确。

固定资料变化后，后台按块增量建索引，未变化的文本块复用向量。过渡期回退原检索，不将旧向量冒充新资料。手动重建命令：

```powershell
.semantic-venv/Scripts/python.exe scripts/build_semantic_index.py
```

仅首次允许下载时加 `--allow-download`。模型、向量、Worker状态与缓存位于 `runtime/semantic/`，独立环境位于 `.semantic-venv/`；均不随源码包、ZIP或Git提交分发。

## 时间感知边界

按账号会话及实际对象记录成功交流时间，数据为各会话目录的 `exchange-time.private.json`。QQ以成功发送回执为准，失败、UNKNOWN和重复回执不推进时间；测试窗口在正文显示并确认后记录。不同群、私聊、对象和独立测试会话不混用。

短间隔同日聊天不添加时间提示；跨天或较长间隔只提供可靠的间隔信息，由当前角色结合话头自然使用。不据此推测谁离线、睡觉、工作或思念，不改变主动发言频率，也不补造生活经历。首次没有记录就不猜，不回填旧聊天时间；状态有期限与数量上限，不在每轮复制全部时间记录。

## 验证与限制

本地179项离线回归、3项最终回复交付测试及合成QQ群聊/私聊传输检查通过；发布源码含额外的便携配置和授权范围测试，数量以发布验证报告为准。隔离索引检查验证只重算修改块、复用未变块并保留阶段信息。固定资料构建为2521块，角色及原作知识40项SHA-256未变。

本机30次热缓存检索样本P95约27毫秒；两次实际Luna回复约7.3秒、11.7秒，均没有额外网页搜索。这些是本机样本，不能保证新机器冷启动、复杂问题或模型网络耗时。无须为发布验证再次消耗模型额度。
