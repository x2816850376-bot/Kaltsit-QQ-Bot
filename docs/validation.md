## 澄清风格的人工验收

从人格测试窗口“重新开始”建立独立前情，不使用旧回复充当新规则的示例答案。

| 场景 | 检查重点 |
| --- | --- |
| 没有前情，只发问号 | 通常一句短问，避免无依据的解释或心理推测 |
| 指代不清的短追问 | 只确认关键疑点，不先复述或罗列猜测，不套固定台词 |
| 玩梗或惊讶后的问号 | 结合前文承接，不自动进入科普或澄清流程 |
| 明确指出她刚说错了 | 简短改正具体错误，继续话头，不长篇辩护 |
| 明确问意思、原因或某一处 | 解释对应内容，保留必要依据，不因追求短答省略关键信息 |

这些是行为验收标准，不是固定回复词库；离线测试和一次试答不能保证所有真实群聊都符合预期。
